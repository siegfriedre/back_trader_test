# A：仅 MA200

参数名：`ma200`

## 目标

对比固定进攻配置，单独检验长期趋势退出是否改善收益与回撤。

## 规则

QQQ高于MA200：持有profile的进攻配置。QQQ低于MA200：100%SGOV。等于MA时保持此前趋势，初始保守。不使用ROC决定杠杆，不使用RSI抄底，但共同预热条件仍和其他版本一致。

profile为tqqq70、qld70、qld100、tqqq46，具体比例见运行指南；没有105%QLD或额外融资。

## 资金与时序

初始80,000美元，每月首个交易日收盘追加1,500美元，初始月不重复。信号至少下一交易日收盘执行；状态切换重设配置，默认月度再平衡。state_only模式月度仅使用新增资金补低配。预热期间持有无息USD，不回填MA200。没有战术仓。

## Review

比较hold_leveraged→ma200，核对STATE_CHANGE、REGIME_REBALANCE的signal_date和execution_date。成本为买卖单边默认5bps，按实际净买卖腿扣除；回撤用剔除定投影响的单位净值，不按账户余额掩盖亏损。

```bash
python run_comparison.py --accept-legacy-adjusted --strategies hold_leveraged ma200 --profiles tqqq70 qld70
```

post_tqqq股票为观测收益、现金早期仍为代理；long_history含上市前模型，VTV预热亦可能用代理；all_observed不等于独立核实价格。详见 [运行指南](../../BACKTEST_GUIDE.md)。
