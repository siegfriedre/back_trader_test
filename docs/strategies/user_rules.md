# 原始描述的明确解释版

参数名：`user_rules`。这不是声称用户未说清的细节只有一种正确解释，也不是参数优化结果。

## 保留的原始差异

首次共同指标预热完成后，强制按所选profile进攻配置建仓一次（tqqq70对应原始70%TQQQ/30%SGOV）。随后按B的MA200/ROC管理。初始处于熊市时，强制建仓可能在下一执行日退出，此行为会完整记录。

牛市独立RSI6超卖事件：卖出当时SGOV余额的5%对应金额，买入profile进攻ETF，即使ROC>0刚去掉杠杆也这样做。熊市独立超卖事件：最多账户当时总净值5%买QQQ。二者分母不同，买卖成本扣除后实际成交会略小；现金不足减量，不借款。

没有建议版的10%累计战术上限，也没有RSI50/持有10天退出。战术仓一直持有到下一次基础状态或ROC档位变化后重设。因此熊市重复独立信号可能让股票仓明显累积。

## 为消除歧义明确加入的约定

RSI从>=21跌至<21且已经武装才触发；RSI>=30后重新武装，不是每天低于21都买。基础状态切换日退出/重设优先，禁止新抄底并消费该次信号。熊市下方并非每天强制清仓，否则会把刚买入的QQQ在次日卖掉。

默认每月首交易日收盘定投1,500美元并再平衡；初始80,000美元、初始月不重复定投。普通再平衡保留战术仓，底仓目标加战术仓占用SGOV。可用state_only关闭常规主动卖出，但状态变化仍重设比例。

## 执行与Review

所有版本共同等待完整指标、等待期间无息USD；信号至少下一交易日收盘执行，不虚构开盘或盘中价格。默认单边成本5bps，指数金额记账，不含税。QLD100没有SGOV时不允许借钱抄底。

```bash
python run_comparison.py --accept-legacy-adjusted --strategies user_rules bull_bear_rsi --profiles tqqq70 qld70 --verbose-trades
```

逐笔核对INITIAL_ALLOCATION、REGIME_REBALANCE、BULL_DIP_BUY和BEAR_DIP_BUY，特别核对牛市5%SGOV与熊市5%净值的金额。与D比较的差异包含上述明确约定，不应称作只有一个参数改变。数据和窗口限制见 [运行指南](../../BACKTEST_GUIDE.md)。
